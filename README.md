# Summer Camp Arcade

A collection of standalone HTML5 games. Open `index.html` for the arcade hub that links to all of them.

| File | Game | Description |
|---|---|---|
| `index.html` | Summer Camp Arcade | Hub page linking out to every game below. |
| `banana.html` | Banana Quest: Four Worlds | Platformer — jump through the jungle to find the banana. |
| `corgiblox.html` | Corgiblox Block Jump | Blocky platformer — hop across worlds as a corgi. |
| `mafia.html` | Agent vs Mafia | Undercover action shootout, mobile & laptop support. |
| `moon_clicker_game.html` | Moon Clicker | Idle clicker — click the moon and build a lunar empire. |
| `neon_drop_royale.html` | Neon Drop Royale | Top-down arena battle with bots, teams, and online two-player. |
| `token_strike.html` | Token Strike 3D | First-person shooter. |
| `turbo_kart_rush.html` | Turbo Kart Rush | Kart racer — drift, boost, and unlock karts in the garage. |
| `block_heroes_tower_defence_upgrades.html` | Block Heroes Tower Defence | Tower defense — place and evolve heroes, stop a two-phase boss. |
| `neon_dash_poc.html` | Neon Dash | Fast neon endless runner, two levels. |
| `clockwork_wave_dash.html` | Clockwork Wave Dash | Wave-style flying dash through a steampunk city with a giant boss fight on Hard. |
| `orb_clicker_mobile.html` | Asian Orb Clicker | Idle/active clicker with abilities, a heat/overheat system, and mobile-first controls. |

External (not a local file): **GPT Street Fighter** — linked from the hub at `https://gtpstreetfighter.vercel.app/`.
